With Laravel

Canon in a Laravel app: its files in public/, Blade components for every form part, errors, flash messages as toasts, and the paginator drawing Canon's Pagination. For adding Canon to a page, start with Getting started.

Set up

Canon is two files, and public/ serves them as they are. Take them from the npm package (keep the css folder whole: a stylesheet finds its icons and fonts beside it):

Terminal 
npm i canon-ui
mkdir -p public/canon/js
cp -R node_modules/canon-ui/css public/canon/
cp node_modules/canon-ui/js/canon.js public/canon/js/

Then link them in your layout:

resources/views/layout.blade.php 
<link rel="stylesheet" href="{{ asset('canon/css/canon/canon.css') }}">
<script src="{{ asset('canon/js/canon.js') }}" defer></script>

Or link both from a CDN, as Getting started shows. Either way there's nothing to build and no package to add.

Fields as Blade components

Three anonymous components write Canon's form parts. A field takes its name, label and kind, and finds its own error ($errors) and old value (old()), so a form sent back keeps what was typed:

resources/views/components/canon/field.blade.php 
@props([
    'name',
    'label',
    'type' => 'text',
    'hint' => null,
    'value' => null,
    'options' => [],
    'required' => false,
    'id' => null,
])
@php
    $id ??= $name;
    $error = $errors->first($name);
    $describedBy = trim(($hint ? "{$id}-hint " : '') . "{$id}-error");
    $current = old($name, $value);
@endphp
<div class="canon-field">
    <div class="canon-label">
        <label class="canon-label-text" for="{{ $id }}">{{ $label }}@unless ($required) <span class="canon-label-optional">(optional)</span>@endunless</label>
        @if ($hint)
            <p class="canon-label-description" id="{{ $id }}-hint">{{ $hint }}</p>
        @endif
    </div>
    @switch($type)
        @case('textarea')
            <div class="canon-textarea">
                <textarea id="{{ $id }}" name="{{ $name }}" placeholder @required($required) aria-describedby="{{ $describedBy }}" @if ($error) aria-invalid="true" @endif {{ $attributes }}>{{ $current }}</textarea>
            </div>
            @break
        @case('select')
            <div class="canon-select">
                <select id="{{ $id }}" name="{{ $name }}" @required($required) aria-describedby="{{ $describedBy }}" @if ($error) aria-invalid="true" @endif {{ $attributes }}>
                    @foreach ($options as $optionValue => $optionLabel)
                        <option value="{{ $optionValue }}" @selected((string) $current === (string) $optionValue)>{{ $optionLabel }}</option>
                    @endforeach
                </select>
            </div>
            @break
        @case('date')
            <div class="canon-date">
                <input type="date" id="{{ $id }}" name="{{ $name }}" value="{{ $current }}" @required($required) aria-describedby="{{ $describedBy }}" @if ($error) aria-invalid="true" @endif {{ $attributes }}>
            </div>
            @break
        @case('password')
            <div class="canon-password">
                <input type="password" id="{{ $id }}" name="{{ $name }}" placeholder @required($required) aria-describedby="{{ $describedBy }}" @if ($error) aria-invalid="true" @endif {{ $attributes }}>
                <button type="button" class="canon-button" data-emphasis="minimal" data-display="icon" aria-pressed="false" commandfor="{{ $id }}" command="--canon-toggle-password">
                    <span class="canon-icon" data-icon="eye" aria-hidden="true"></span>
                    <span class="canon-button-label">Show password</span>
                </button>
            </div>
            @break
        @default
            <div class="canon-text-input">
                <input type="{{ $type }}" id="{{ $id }}" name="{{ $name }}" value="{{ $current }}" placeholder @required($required) aria-describedby="{{ $describedBy }}" @if ($error) aria-invalid="true" @endif {{ $attributes }}>
            </div>
    @endswitch
    <p class="canon-field-message" id="{{ $id }}-error" @if ($error) data-intent="danger" @endif>{{ $error }}</p>
</div>

It writes a Text Input, Textarea, Select, Date or Password in a Field, ties the description and message to the control (aria-describedby, aria-invalid), adds the empty placeholder Canon's text boxes need, and says "(optional)" unless the field is required. A Checkbox and radios in a Fieldset:

resources/views/components/canon/checkbox.blade.php 
@props(['name', 'label', 'id' => null, 'checked' => false])
@php
    $id ??= $name;
    $error = $errors->first($name);
@endphp
<div class="canon-choice">
    <input type="checkbox" id="{{ $id }}" name="{{ $name }}" value="1" @checked(old($name, $checked)) aria-describedby="{{ $id }}-error" @if ($error) aria-invalid="true" @endif {{ $attributes }}>
    <label class="canon-choice-label" for="{{ $id }}">{{ $label }}</label>
    <p class="canon-choice-message" id="{{ $id }}-error" @if ($error) data-intent="danger" @endif>{{ $error }}</p>
</div>
resources/views/components/canon/radios.blade.php 
@props(['name', 'legend', 'options', 'hint' => null, 'value' => null, 'required' => false])
@php
    $error = $errors->first($name);
    $current = old($name, $value);
@endphp
<fieldset class="canon-fieldset" aria-describedby="{{ trim(($hint ? "{$name}-hint " : '') . "{$name}-error") }}">
    <legend class="canon-fieldset-legend">{{ $legend }}</legend>
    @if ($hint)
        <p class="canon-fieldset-hint" id="{{ $name }}-hint">{{ $hint }}</p>
    @endif
    @foreach ($options as $optionValue => $optionLabel)
        <div class="canon-choice">
            <input type="radio" id="{{ $name }}-{{ $optionValue }}" name="{{ $name }}" value="{{ $optionValue }}" @checked((string) $current === (string) $optionValue) @required($required) @if ($error) aria-invalid="true" @endif>
            <label class="canon-choice-label" for="{{ $name }}-{{ $optionValue }}">{{ $optionLabel }}</label>
        </div>
    @endforeach
    <p class="canon-fieldset-message" id="{{ $name }}-error" @if ($error) data-intent="danger" @endif>{{ $error }}</p>
</fieldset>

Using them

Each field is one tag. A canon-form spaces them:

resources/views/invoices/create.blade.php 
@extends('layout')

@section('content')
<h1>New invoice</h1>
<form class="canon-form" method="post" action="{{ route('invoices.store') }}" novalidate>
    @csrf
    <x-canon.field name="customer" label="Customer" required />
    <x-canon.field name="email" type="email" label="Email" hint="Where the invoice is sent." required />
    <x-canon.field name="status" type="select" label="Status" :options="['draft' => 'Draft', 'sent' => 'Sent', 'paid' => 'Paid']" />
    <x-canon.field name="due" type="date" label="Due" required />
    <x-canon.field name="notes" type="textarea" label="Notes" />
    <x-canon.field name="portal_password" type="password" label="Portal password" />
    <x-canon.radios name="channel" legend="Channel" hint="How the invoice reaches them." :options="['email' => 'Email', 'post' => 'Post']" required />
    <x-canon.checkbox name="reminders" label="Send reminders when overdue" />
    <button type="submit" class="canon-button" data-emphasis="high"><span class="canon-button-label">Save</span></button>
</form>
@endsection

Extra attributes go to the control: <x-canon.field name="zip" label="Postcode" autocomplete="postal-code" />.

Errors

validate() sends a form with errors back with its messages and what was typed, and the components show them:

app/Http/Controllers/InvoiceController.php 
public function store(Request $request)
{
    $data = $request->validate([
        'customer' => 'required',
        'email' => 'required|email',
        'due' => 'required|date',
        'channel' => 'required|in:email,post',
    ]);

    Invoice::create($data);

    return redirect()->route('invoices.index')->with('status', "Invoice for {$data['customer']} saved.");
}

An email field after a failed save:

Rendered 
<div class="canon-field">
    <div class="canon-label">
        <label class="canon-label-text" for="email">Email</label>
        <p class="canon-label-description" id="email-hint">Where the invoice is sent.</p>
    </div>
    <div class="canon-text-input">
        <input type="email" id="email" name="email" value="nope" placeholder required aria-describedby="email-hint email-error" aria-invalid="true">
    </div>
    <p class="canon-field-message" id="email-error" data-intent="danger">The email field must be a valid email address.</p>
</div>

The browser's own checks (required, type="email") run first unless the form has novalidate, and canon.js shows their messages in the same place.

Flash messages as toasts

A redirect's status ("Invoice saved") shows as a Toast. At the end of the layout:

resources/views/layout.blade.php 
@if (session('status'))
    <p id="status" data-intent="success" hidden>{{ session('status') }}</p>
    <script>
        addEventListener("DOMContentLoaded", () => {
            const status = document.getElementById("status");
            document.dispatchEvent(new CustomEvent("canon-toast", {
                detail: { intent: status.dataset.intent, title: status.textContent },
            }));
        });
    </script>
@endif

A toast needs JavaScript. A message people must read even without it (a save that failed) belongs in the page, as an Alert.

Lists and pages

Laravel's paginator draws its links with a view, so one view makes every links() Canon's Pagination:

app/Providers/AppServiceProvider.php 
<?php

namespace App\Providers;

use Illuminate\Pagination\Paginator;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Paginator::defaultView('canon.pagination');
    }
}
resources/views/canon/pagination.blade.php 
@php
    $pattern = preg_replace('/(' . preg_quote($paginator->getPageName(), '/') . '=)1$/', '$1{page}', $paginator->url(1));
@endphp
<nav class="canon-pagination" aria-label="Pagination"
     data-pages="{{ $paginator->lastPage() }}" data-page="{{ $paginator->currentPage() }}" data-href="{{ $pattern }}">
    <ol>
        <li>
            <a class="canon-pagination-prev" @if ($paginator->onFirstPage()) aria-disabled="true" @else href="{{ $paginator->previousPageUrl() }}" rel="prev" @endif>
                <span class="canon-icon" data-icon="chevron-left" aria-hidden="true"></span>
                <span class="canon-pagination-label">Previous</span>
            </a>
        </li>
        <li><span class="canon-pagination-current">Page {{ $paginator->currentPage() }} of {{ $paginator->lastPage() }}</span></li>
        <li>
            <a class="canon-pagination-next" @if ($paginator->hasMorePages()) href="{{ $paginator->nextPageUrl() }}" rel="next" @else aria-disabled="true" @endif>
                <span class="canon-pagination-label">Next</span>
                <span class="canon-icon" data-icon="chevron-right" aria-hidden="true"></span>
            </a>
        </li>
    </ol>
</nav>

With data-pages and data-page, canon.js draws the page numbers and fits them to the room; the list written inside is what shows without JavaScript: Previous, "Page 4 of 10", Next. data-href is the paginator's own link with {page} in it, so with withQueryString() every page keeps the list's filters.

app/Http/Controllers/InvoiceController.php 
public function index()
{
    return view('invoices.index', [
        'invoices' => Invoice::latest('issued_on')->paginate(25)->withQueryString(),
    ]);
}
resources/views/invoices/index.blade.php 
<table class="canon-table">
    <thead>…</thead>
    <tbody>
        @foreach ($invoices as $invoice)
            <tr><td>{{ $invoice->number }}</td><td>{{ $invoice->customer }}</td><td data-align="end">{{ $invoice->total }}</td></tr>
        @endforeach
    </tbody>
</table>
{{ $invoices->links() }}

With htmx

Everything on With htmx applies; Laravel adds its CSRF token to every request htmx sends:

resources/views/layout.blade.php 
<body hx-headers='{"X-CSRF-TOKEN": "{{ csrf_token() }}"}'>

Partials are the same components: a route that answers htmx renders a field, a form or a table on its own, and canon.js sets it up when it lands.
