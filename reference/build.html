Build

Canon in full is three files with every component. If your app uses only some of them, build Canon with just those: the smaller files behave exactly like the full ones.

Bundles

Core is always in. Add the bundles your app uses; point at a bundle's components to see what's in it. For single components, the command line takes them one at a time (npx canon-ui build --list).

Files

Put them where the full ones would go: canon.css and canon.core.css side by side (the first imports the second), canon.js anywhere. The page links one stylesheet and one script, as with the full build.

From the command line

The same build, in your project: this writes the three files to canon/, or to the folder --out names. npx canon-ui build --list shows the bundles and the components.

Terminal 
npx canon-ui build
