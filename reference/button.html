Button

An action (<button>), or a link that looks like one (<a>). Specification: docs/components/button.md

Emphasis × intent

Four emphases (data-emphasis) by five intents (data-intent): 20 variants. Without an intent a button takes the accent; neutral takes none, for ordinary actions that shouldn't draw the eye (Cancel, a toolbar's or a filter bar's buttons, a search trigger).

Opens a menu

Add aria-haspopup and the theme draws the menu indicator; aria-expanded follows the menu as it opens and closes (canon.js keeps it). Open one to see the expanded state; the menu is a Menu.

Copy

A Button with command="--canon-copy" and commandfor naming what it copies: an input's value, or an element's text. For 2 seconds after copying it has data-state="copied" (here the icon becomes a check) and screen readers hear "Copied". In a field's box, see Field.
