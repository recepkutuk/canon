Description List

Facts about one thing, as terms and their values: a record's details, a profile, an invoice's totals, a settings overview. The read-only side of a form: it lines up the same way, so a page can switch between showing and editing without moving. To compare many records, use a Table. Specification: docs/components/description-list.md

Basics

A <dl class="canon-description-list"> with a <div> per item: its term (<dt>) and its value (<dd>). Terms sit above their values; lines run between items.

Icons as terms

A term can be an icon (aria-hidden="true") with its words visually hidden (canon-visually-hidden): the icon sits beside the value, and screen readers still hear "Date, 10 October 2026". For a panel where the icons say enough at a glance (an event, a contact card); data-lines="none" drops the lines.

Values

A value can hold anything inline: a Tag, a Link, a time, a code with a copy button. A term with several values gets a <dd> for each. An empty <dd> shows a dash that screen readers hear as "Not set" (the --canon-text-not-set string).
