Link

Text that goes somewhere: in a sentence, or on its own ("View all invoices"). An <a href>; a <button> can look like one when it does something from inside text. It takes the text's font and size. Specification: docs/components/link.md

Basics

class="canon-link" on an <a href>. In a sentence it is underlined, so it shows by more than its color.

Standalone

data-standalone on a link that stands on its own, outside a sentence: under a list, in a card, in a table cell. Its place says it's a link, so the theme may drop the underline until hover or focus. An icon (aria-hidden="true") can go before or after the text.

Low emphasis

data-emphasis="low": the surrounding text's color, always underlined. For links that shouldn't draw the eye: a footer, fine print, a muted description.

New tab

target="_blank": the theme draws the external icon after the text, and screen readers hear "(opens in new tab)" (the --canon-text-opens-in-new-tab string, translated by i18n/). Open a new tab only when leaving would lose the person's work.

Service status

On a button

When it does something rather than going somewhere, from inside text, it is a <button type="button" class="canon-link">: it looks like a link and behaves as a button (Enter and Space, no address). Anywhere else, use a Button.
