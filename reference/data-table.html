Data Table

A Table people work with: sort it, select rows, act on a row, page through it, and see where it stands while it loads or when there's nothing to show. Specification: docs/components/data-table.md

Basics

A <div class="canon-data-table"> around a Table and a Pagination. Headers with aria-sort sort; the data-column="select" column selects rows (Shift+click selects a range); the data-column="actions" column holds each row's actions, here a Menu. With data-local all rows are in the page, and canon.js sorts them and shows them a page at a time.

Bulk actions

A <div class="canon-data-table-bulk" role="region"> in the data table, named, holding the actions for the selected rows: Buttons by meaning (the main action, data-intent="danger" for a destructive one), a menu button for more. While rows are selected it floats at the bottom of the window, with Clear selection and the count (screen readers hear it change); the app's buttons read the selection from canon-select. Select every row on this page: it offers to select all 12 (here the rows are in the page, so canon.js checks them; for the app's rows, canon-select says allMatching). Without canon.js the bar stays under the table, for a form round trip.

Search, filters, columns, export

A .canon-data-table-toolbar before the table holds a search field (type="search"), a data-panel="filters" button and a data-panel="columns" button; data-align="end" sends an item to the far end. Headers say what their column holds (data-type: text, number, date, choice), which makes them filterable. Filters show as chips under the toolbar: a chip opens its filter, its × removes it; a filtered column also shows a filter button in its header that opens its filter. Columns shows, hides, orders (drag the grip, or its arrow keys) and pins them. An Export item with data-export="csv" downloads the matching rows.

Cut in the middle: file names, paths and ids

data-wrap="middle" cuts a column's text in its middle and keeps its end: its last third, at least 8 characters, and a file name's extension with the 5 characters before it. Use it where values share a start and differ at the end (file names, paths, hashes). The full text shows on hover and is read in full by screen readers.

Editing cells

data-edit on a header makes its cells editable. Click a value (or focus it and press Enter, or start typing), change it, then Enter or click away to save; Escape puts it back. The editor follows the column's data-type (Status is a choice, Review a date), or a template.canon-data-table-editor in the header: Owner is a Combobox, Target a number field that can't be empty or below 0. Each change fires canon-edit; here the page cancels it to save on its own, then answers canon-saved, or canon-save-failed for a target of 0. KPI isn't editable, nor is the last row's Review (data-edit="none"). Specification: docs/components/data-table-editing.md

Editing in a form

In a form with a Save Bar, each editable cell holds its value in a field (<input hidden name>): an edit changes the field, the Save Bar counts it and the cell is marked; Discard puts every value back, Save sends them together. A switch (or checkbox) in an editable column is changed where it is, and counts the same way.

Pinned columns

data-pin on a header keeps its column in view while the others scroll; here, User. The select column and the actions column are always pinned. A pinned column shows a line at its edge; the last one casts a shadow while rows scroll under it. Scroll the table sideways.

Sorting by the app

Without data-local, a sort button fires canon-sort (detail: { index, key, direction }) and updates aria-sort; the app loads the rows in that order. Cancel the event to keep the current order. Sort values come from a cell's data-value, else its <time datetime>, else its text.
